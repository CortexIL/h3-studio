Connect to RunPod

Until a key is set, H3 Studio runs in demo mode: it makes placeholder videos and never rents a GPU. Get a key at runpod.io → Settings → API Keys → Create API Key → permission All. RunPod shows it once, so copy it straight away. You also need credit on the account (minimum $10, non-refundable, does not expire).

The key is checked against RunPod before it is saved, and is stored on this machine only — it is never sent to the browser or committed to git.
